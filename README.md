# Baba Is You · additional recordings

Game-only cropped recordings for the catalogue at https://jehlp.net/baba-is-you/.

This companion repository keeps the growing collection below the per-site GitHub Pages size limit. Catalogue entries 71–118 and the later capacity exceptions, 176 (Floodgates), 178 (AB), 179 (Overgrowth), and 181 (Cleaning Service), use `/baba-is-you-media/media/…` URLs. Posters, metadata and the player remain in [the catalogue repository](https://github.com/JWKNT/baba-is-you).

Publish `main` from the root with no CNAME. Verify new videos are live before publishing catalogue links. Use silent H.264/yuv420p, 1680×960, 30 fps and faststart; keep each file below 100 MiB and this published repository below 1 GB. Originals stay outside Git. Pause-edit manifests and validation evidence live in the catalogue repository.

Game art and gameplay belong to Hempuli. These are recorded playthroughs, not the game.

Entries 119 onward normally use [the second companion](https://github.com/JWKNT/baba-is-you-media-2) at `/baba-is-you-media-2/media/…`. Completions 176, 178, 179, and 181 use `/baba-is-you-media/media/176-floodgates.mp4`, `/baba-is-you-media/media/178-ab.mp4`, `/baba-is-you-media/media/179-overgrowth.mp4`, and `/baba-is-you-media/media/181-cleaning-service.mp4`; entries 177, 180, and 182 onward retain the second-companion default. Existing recordings and URLs remain in this store.
